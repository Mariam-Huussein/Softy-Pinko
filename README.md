# Softy Pinko Template 

A simple and elegant marketing template built as part of an internship task. This template can be used for creating marketing landing pages, showcasing products, or gathering user inputs through interactive forms.

## Features
- **Responsive design**: The layout adapts seamlessly to different screen sizes (mobile, tablet, and desktop).
- **Interactive Contact Forms**: Users can easily get in touch through well-designed forms.
- **Hover Effects**: Interactive hover effects on elements like buttons and images to enhance user experience.
- **Clean & Modern Design**: Simple yet modern design, suitable for marketing purposes.

## Technologies Used
- **HTML5**
- **CSS3**
- **Responsive Web Design** (using media queries)


## Folder Structure
```
Softy Pinko/
```
